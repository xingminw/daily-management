# Playbook · 每日摘要（daily brief）

**场景**：每天早上生成一段"今天该干什么"的摘要。
**状态**：📝 手动阶段；跑顺后可固化为 WorkBuddy 定时任务。

## 数据源（按此顺序拼装）

```bash
# 1. 今日日程
lark-cli calendar +agenda

# 2. 细碎待办（未完成）
lark-cli task +list --help   # 按未完成过滤

# 3. 工作项（需 base 域授权后启用；按状态=进行中/等待 + P0/P1 过滤）
#    Base: F9p4bjm24axBY8sd8macJIySnYe / 表 tbldFwiuV4K0l2Lp
#    参见 docs/workflow.md 的工作项推进规则

# 4.（可选）腾讯会议今日日程已在飞书日历里，不用单独查
```

## 输出格式（给用户看的）

```
## 8月21日 · 周五

**今天 3 件事**
1. 10:00–10:45 腾讯会议：赵国任（会议号 937898861）
2. ...

**待办 n 条**：最紧的 3 条列出，其余报数
**工作项**：进行中 n 个，其中 P0 x 个、等待 n 个（等什么）
```

## 固化为定时任务（后续）

WorkBuddy automations：每工作日 08:30 跑一次，输出到对话 + 可选推送飞书消息。
